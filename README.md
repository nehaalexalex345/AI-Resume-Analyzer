# AI Resume Analyzer 🚀

An AI-powered Resume Analyzer built using MERN Stack.

## Features

- Upload Resume
- Analyze resume content
- Extract skills
- Find missing skills
- Compare resume with job requirements

## Tech Stack

### Frontend
- React.js
- Vite
- CSS

### Backend
- Node.js
- Express.js
